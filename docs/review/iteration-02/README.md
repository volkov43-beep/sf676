# СФ676 — визуальная итерация 02

База: `main` на коммите `43da7e0b73109d3adcf4ac4eab1dae966976ba04` после объединения PR #3. Рабочая ветка: `feature/sf676-design-iteration-02`. Основная ветка и опубликованная страница этой работой не изменяются.

## Что изменилось

- **Цена (`#price`)**: единая последовательность 50% → 45% → 5%; на телефоне — вертикально. У окончательного платежа остаётся нейтральное условие договора и редакторский вопрос. Срок изготовления, доставка, упаковка/консервация и лизинг вынесены в четыре компактных блока. Все исходные коммерческие условия и CTA сохранены.
- **Сравнение (`#compare`)**: три равноправные карточки с кратким описанием сценариев; полная таблица доступна в нативном `details/summary`. Сохранены все восемь критериев и исходные значения, включая оценочный ориентир ремонта до 75% и расчёт по дефектной ведомости. На узком экране каждый критерий содержит три подписанных значения. Кнопка ведёт к обращению, автоматический расчёт не имитируется.
- **Комплектация (`#config`)**: пять последовательных блоков A–E с вариантами и объяснением выбора. Сжатая таблица и большая фотографическая заглушка удалены. Сохранены все варианты, пояснения, вопрос по столу, дополнительная оснастка, условия услуг и CTA. Это информационный раздел без элементов конфигуратора.
- **Поставка (`#delivery`)**: десять исходных этапов объединены в четыре группы, с прежними номерами и полными пояснениями. Услуги разделены на включённые и оплачиваемые отдельно. Условие об отдельной оплате командировочных расходов показано постоянно. Сохранены согласование приёмки за неделю, консервация на год, расчёт доставки в КП, платная организация разгрузки и гарантия 12 месяцев. Заглушка фотографии отгрузки сохранена.
- **Служебная полоса полностью удалена** из HTML вместе с CSS и обработчиками переключателей. Обычная закреплённая шапка сохранена у верхней границы окна. Якоря учитывают только её фактическую высоту. Пустого места сверху нет.

Используются существующие токены `.v1`, палитра, типографика, контейнер и кнопки. Изменения не подключают библиотеки, шрифты или изображения. `noindex, nofollow` сохранён.

## Режим вопросов

Обычная страница открывается без редакторской подсветки. `?review=1` показывает отметки и список вопросов без панели управления. Прямая ссылка на вопрос или пункт списка также включает этот режим; при необходимости раскрывается соответствующий FAQ.

Сохранены все **13 уникальных вопросов и 15 сносок актуальной main**. Повторные вхождения имеют отдельные уникальные ID; обратная ссылка списка ведёт к первому вхождению. Словарь вопросов совпадает с базовой версией. Неуточнённые условия остаются обозначены в обычном тексте.

## Проведённые проверки

Среда: Chromium **153.0.8010.0**, headless, Playwright; локальная страница и HTTP с префиксом `/sf676/`. Мобильные размеры эмулированы браузером.

| Проверка | Результат |
|---|---|
| 320, 375, 390, 768, 1024, 1366, 1920 px | Пройдены в обычном и редакторском режимах, со свёрнутым/раскрытым сравнением и раскрытым FAQ |
| Горизонтальное переполнение | `scrollWidth` страницы равен ширине окна во всех проверенных состояниях; причины не маскируются `overflow-x: hidden` |
| Текст в новых карточках, таблице, условиях и кнопках | Проверены границы текстовых фрагментов и снимки; обрезания не обнаружены |
| Увеличение текста до 200% | На каждой ширине проверено удвоение вычисленных размеров шрифта, с раскрытой таблицей и вопросами; информация доступна, переполнения страницы нет |
| JavaScript / загрузка | Ошибок страницы, консоли и загрузки ресурсов в проверенных сценариях нет; относительные изображения работают через `/sf676/` |
| Контент | 13 основных экранов сохранены в прежнем порядке. Все 8 строк сравнения, варианты и пояснения 5 параметров, названия и описания 10 этапов сверены с main |
| Остальные экраны | HTML девяти остальных секций совпадает с main. Их размеры совпадают на 390/1366 px |
| Первые три экрана | Снимки каждого экрана на 390/1366 px совпадают с базой пиксель в пиксель |
| Вопросы и ID | 13 вопросов, 15 сносок; повторов ID и несуществующих локальных целей нет. Проверены все обратные переходы и 28 прямых URL к вхождениям вопросов/пунктам списка |
| Шапка и якоря | Шапка появляется при прокрутке, её верхняя координата 0. Заголовки всех секций доступны после якорного перехода; проверены плавная прокрутка и переходы с увеличенным текстом |
| Клавиатура | Tab, Enter, Space: CTA, нативное раскрытие/закрытие сравнения, переход к обращению. Видимый фокус; для тёмного сравнения применён контрастный золотой контур |

| Семантика | Сохранён H1, разделы H2, карточки H3, внутренние пояснения H4; у таблицы заголовки столбцов и строк `scope`; нативные списки и `details/summary` |

Расчёт контраста применённых цветов: белый текст на красной кнопке **6,02:1**; серый текст на светлом фоне **4,89:1**; второстепенные подписи на тёмном фоне **7,12:1**; золотой фокус на тёмном фоне **6,69:1**. Это проверка отдельных применимых аспектов доступности, а не заявление о полной сертификации WCAG.

## Изменённые файлы и ограничения

- `index.html` — только четыре согласованных раздела, удаление панели и связанные общие CSS/JS.
- `docs/review/iteration-02/README.md` — этот отчёт.
- `docs/review/iteration-02/screens/*.webp` — 18 снимков до/после и раскрытого сравнения.

Нерешённых ошибок в проверенных сценариях не обнаружено. Физические телефоны, Safari/Firefox и экранные дикторы не проверялись. Увеличение текста проверено программным удвоением размеров, а не системными настройками всех платформ. Генерация редакторских сносок и появление шапки по прокрутке по-прежнему требуют JavaScript. Исходные заглушки формы обращения, PDF и интеграций остаются вне этой итерации.
