## Производительность

Сравнение выполнено в одном браузере и на одном локальном сервере, без ограничения CPU/сети. По четыре чередующихся запуска каждой версии на 390 и 1366 px; запуск 0 — прогрев, ниже медиана оставшихся трёх. Кэш прогрет, результаты не характеризуют первую загрузку через интернет.

| Ширина | DOMContentLoaded до / после, мс | load до / после, мс |
|---|---:|---:|
| 390 | 44.6 / 57.3 | 51.8 / 67.4 |
| 1366 | 42.2 / 56.2 | 46.8 / 66.1 |

Стили оставлены внутри HTML: нет дополнительного блокирующего CSS-запроса. SVG-файл — 9 466 байт, около 2,3 КБ при gzip. Новых скриптов нет. Фактическая компрессия на GitHub Pages зависит от сервера.

**Ограничение:** наблюдались дополнительные ранние запросы уже существующих изображений в версии после изменений. Перенос CSS внутрь HTML не устранил это наблюдение; причина не подтверждена. Настройки lazy-loading, `picture`, `srcset` и приоритет главного снимка сохранены. Нельзя заявлять, что загрузка первого экрана не ухудшилась. Отдельная проверка холодного кэша на целевом хостинге остаётся необходимой до коммерческого запуска.

LCP в этой iframe-методике не был зарегистрирован; ноль в сырых данных означает отсутствие измерения, а не мгновенную отрисовку. Наблюдатель сдвигов не зарегистрировал событий, однако это не доказывает отсутствие CLS в реальных условиях. Статически проверено резервирование места под изображения и SVG. Lighthouse не запускался: доступный управляемый браузер не предоставляет его интерфейс. Полевая скорость и пользовательское время понимания не измерялись.
