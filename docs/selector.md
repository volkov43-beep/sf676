# Предварительный подбор СФ676 · v1

Два пути в существующем #config: `exact` (пять параметров) и `quiz` (пять вопросов о задачах). Модель/справочники и валидация — `sf676-selector-model.js`; состояние, шаги и DOM — `sf676-selector.js`. Использованы принципы NeuroLab R09/R10/R06/R12/R13/R16 без переноса чужого кода или стека.

- Нет значений по умолчанию в самостоятельном выборе. «Нужна консультация» — отдельный ID `consultation`.
- При изменении `dro` очищается `coordinates`. Для `dro_none` устанавливается `not_applicable` и показывается объяснение; шаг остаётся в последовательности. Это зависимость отображения УЦИ, не матрица совместимости станка.
- Квиз хранит требования, не преобразует их в параметры станка. «Нужна консультация» в операциях взаимоисключается с конкретными операциями; остальные операции можно сочетать.
- Описание деталей и дополнительные требования необязательны. Текст ограничен 1 000 символами; HTML/управляющие символы отклоняются. Контакты просят вводить только в отдельной форме.
- Режимы сохраняют независимые ответы только в памяти страницы. Сброс очищает активный режим, перезагрузка — оба. Не создаются цена, заводской индекс или техническая рекомендация.

## Интерфейс и данные

`SF676Selector.start('exact' | 'quiz')` открывает сохранённый шаг режима и возвращает boolean. `reset(mode)` очищает указанный режим. `getResult()` возвращает независимый валидированный снимок активного режима либо `null`, если ответы не завершены. Состояние с персональными данными, URL/storage и глобальная шина событий не используются.

```js
// exact: фактические ID из справочника, не демонстрационные значения по умолчанию
{ schemaVersion: 1, mode: 'exact', selections: {
  table: 'table_250x800', taper: 'taper_40at5', dro: 'dro_none',
  coordinates: 'not_applicable', screw: 'consultation'
}, requiresConfirmation: true }
```

В `quiz` вместо `selections`: `requirements: {operations: string[], parts: {description, dimensionsUnknown}, tooling, positioning, extras: {items: string[], comment}}`; флаг `requiresConsultation: true`. Значения принимаются только из справочников. Неизвестная версия/режим/ID, лишние поля, дубликаты, неверные типы и устаревшие координаты отклоняются через `SF676SelectorModel.validateResult`. Это клиентский контракт, серверную проверку предстоит реализовать отдельно.

Итоговая ссылка сохраняет `href="#order"`. При наличии API форм вызывает:

```js
SF676Requests.open({
  formId: 'configuration_help', sourceSection: 'config',
  sourceCta: 'selector-exact-result', // либо selector-quiz-result
  context: {selector: SF676Selector.getResult()}, trigger: clickedLink
});
```

Общая форма повторно проверяет `context.selector`, показывает сводку и возвращает её в `getDraft().context.selector`. Для квиза убрано повторное поле производственной задачи, остальные поля формы сохранены. Неверный контекст отклоняет открытие. Закрытие очищает поля/контекст формы, но оставляет технические ответы мастера для изменения. Без API форм ссылка ведёт к резервным контактам.

Без JS мастер скрыт; исходные пять карточек доступны в нативном `details`. Формы, CRM, аналитика и реальные заявки не подключаются.

## Проверки

- `node --test tests/selector-model.test.cjs` — все варианты, неизвестные ID/типы, зависимость УЦИ, необязательные ответы, границы текста, раздельные режимы и независимые снимки.
- `python tests/verify-selector-preservation.py BASELINE index.html` — сохранение исходных карточек, остальных 12 экранов, таблиц, фото, SVG, вопросов, контактов и noindex.
- `tests/selector.html` через HTTP — оба маршрута, возврат/правки/сброс, передача в форму, 320/390/768/1366, текст 200%, no-JS и отсутствие API форм. `tests/request-forms.html` сохраняет проверки общей системы форм из итерации 06.
- Реальные клавиши и визуальную компоновку проверять дополнительно. Эмуляция в Chromium не заменяет физические телефоны, Safari/Firefox или экранный диктор.

Требуют подтверждения завода: матрица совместимости исполнений, правила заводского индекса, точное исполнение столов/пазы, пригодность оборудования под конкретную деталь и операцию. Интерфейс не принимает эти решения за завод.
