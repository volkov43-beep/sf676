# СФ676 · кнопки в характеристиках и приёмке

В конце двух разделов посетитель может обратиться к технологу по поводу своей детали или требуемой точности. Обе ссылки открывают существующую форму «Поможем подобрать комплектацию СФ676». База сравнения — `main` на коммите `d595617`.

| Раздел | Текст кнопки | `sourceSection` | `sourceCta` |
| --- | --- | --- | --- |
| Характеристики | Проверить станок под мою деталь | `specs` | `specs-fit` |
| Приёмка и точность | Подобрать класс точности под мою задачу | `acceptance` | `acceptance-accuracy` |

На странице 10 ссылок с `data-request-form`. У каждой есть запасной переход `href="#order"`. Обе новые ссылки имеют класс `btn out` и сценарий `configuration_help`. Общая обёртка `.section-cta` завершает соответствующую `.wrap` и задаёт отступ сверху `var(--ui-space-4)` (32 px).

## Проверки

| Проверка | Результат |
| --- | --- |
| Матрица в Chrome | Все 10 кнопок при ширинах 320, 375, 390, 768, 1024, 1366 и 1920 px, в обычном режиме и с размером текста 200%. Для обеих новых кнопок проверены заголовок, описание, поля, геометрия окна, источник в `SF676Requests.getDraft()` и возврат фокуса. |
| Без JavaScript | Нажатие каждой новой ссылки в браузере с отключёнными скриптами переводит к видимой секции `#order`. |
| Валидация и API | Все 52 проверки существующих сценариев прошли на синтетических данных. Демонстрационная форма не отправляет заявки. |
| Мобильная вёрстка | На 320 и 390 px обе кнопки имеют высоту 70,4 px. На 568 px высота 51,2 px. На всех трёх ширинах кнопки занимают всю колонку. С 569 px их ширина определяется текстом. Горизонтального переполнения нет. |
| Сравнение расположения с базой | Сверены координаты и размеры 106 прежних элементов в характеристиках и 74 в приёмке относительно начала каждой секции. На ширинах 320, 390, 568, 569, 768, 1024, 1366 и 1920 px максимальная разница меньше 0,001 CSS-пикселя. |
| Сохранность | Три проверки прошли. Из сравнения исключаются только две проверенные по тексту, месту и атрибутам обёртки и их точные правила CSS. Затем сравнивается вся остальная страница, включая шапку, 13 секций, исходные кнопки, таблицы, фото, `data-q` и `noindex, nofollow`. Шесть намеренных искажений в контрольных копиях вызвали отказ проверки. |
| Проверки из `pr-checks.yml` | Синтаксис JavaScript и Python, все 20 тестов Node.js, данные 90 точек поставок, резервный справочник и сборка статического сайта прошли. |

Для повторения браузерных проверок открыть [стенд форм](../../tests/request-forms.html) через локальный HTTP-сервер и последовательно запустить «Проверить матрицу» и «Проверить валидацию / API». Сравнение с базой можно повторить из корня репозитория.

```sh
git show d595617:index.html > /tmp/sf676-before-section-cta.html
for script in tests/verify-preservation.py tests/verify-payment-preservation.py tests/verify-selector-preservation.py
do
  python3 "$script" /tmp/sf676-before-section-cta.html index.html || exit 1
done
```

Открытых вопросов по первой части нет.
