# СФ676 · кнопки запроса цены в разделах лендинга

В «Конструкции» кнопка стоит после сетки карточек, в «Поставке и запуске» — после карточек «Входит в стоимость» и «Оплачивается отдельно», в разделе завода — под фотографией производства. Все три используют существующие `.section-cta` и `btn red`. База сравнения — `main` на коммите `1495c5f`, который включает часть 1.

## Карта поставок

На опубликованной странице проверены работа карты Яндекса, приближение и отдаление, переключение фильтров «Россия 73», «Экспорт 17» и «Все 90». При приближении число видимых меток и групп изменилось с 41 до 45, при возврате масштаба снова стало 41. Проверка сохранности подтверждает совпадение разметки карты с базой, а сравнение файлов — совпадение скриптов, стилей и данных карты.

На версии ветки при недоступном API Яндекса в Chrome раскрыт резервный список. В нём 73 российских региона и 17 городов шести зарубежных стран. В мобильном окне шириной 390 px проверены обработчики страницы с программными событиями касания и тестовым адаптером API карты. Свайп и второе касание сохраняют прокрутку страницы. Короткое нажатие включает перемещение и масштабирование карты двумя пальцами. «Вернуть прокрутку страницы» возвращает исходный режим. Открытие и закрытие новой формы сохраняет этот режим. Физический телефон в проверке не использовался.

## Повторение проверок

```sh
git show 1495c5f:index.html > /tmp/sf676-before-part2.html
for test in tests/verify-preservation.py tests/verify-payment-preservation.py tests/verify-selector-preservation.py
do
  python3 "$test" /tmp/sf676-before-part2.html index.html || exit 1
done
node --test tests/delivery-bounds.test.mjs tests/delivery-touch.test.mjs
```
